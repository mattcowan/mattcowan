# Matthew Cowan, CPACC

I am an independent freelance developer, and I build websites and web applications with WordPress, Shopify, PHP, JavaScript, React, and more. I strongly believe in open source and not being locked in to systems, corporate or otherwise.

I don't want to be pigeonholed as just an accessibility-only developer, but I have tried to make it a focus. A long time ago I volunteered at a 'design week' event, basically I was an usher. A group arrived that had people who used wheelchairs. The event was crowded, and there was literally no training for the ushers besides 'stand here and hand out these pamphlets.' I had no idea where the accessible section of the auditorium was or how to handle the situation, and it wasn't possible to get hold of the person in charge of the event. Eventually we figured out where to go by finding a map of the auditorium from a person who worked in maintenance, but when we got there, the sight lines were quite horrible. One of the people I was trying to help commented that this was a failure of design at a design focused event. I really didn't want to feel the way that I felt in that moment ever again. That is why I test my work with a keyboard and with screen readers, so that people who use assistive technology are not presented with barriers by what I build. 

I understand I will never be perfect, but I at least want to be better than I was yesterday.

## My projects

- **[Typography Stylist](https://github.com/mattcowan/typography-stylist-for-wordpress)** — a block editor plugin providing access to OpenType features, alternate glyphs like swashes, and precision control over things like line height, letter spacing, and variable font axes. Allows for paragraph styles to be defined and edited within the WordPress admin by users without writing CSS code. Works as a font manager, only loading font files on pages where they are used, allows fonts to be uploaded or served from remote services and then managed inside WordPress. Screen readers read styled text as plain words, so heavily styled text broken up with span tags does not present accessibility barriers. [WordPress.org](https://wordpress.org/plugins/typography-stylist/)
- **[EditRail](https://github.com/mattcowan/EditRail)** — a movable toolbar for the block editor. Pin blocks or patterns for quick access to remove steps in Gutenberg, insert them where you click or enter, and move sections of long documents. An API allows plugins or themes to register custom buttons. Every action works with a keyboard. [WordPress.org](https://wordpress.org/plugins/editrail/)
- **[POURcast](https://github.com/mattcowan/POURcast)** — a React study app for the IAAP CPACC and WAS exams, with practice quizzes and a reference library. [Use the app](https://www.mnc4.com/pourcast)
- **[Find Blocks, Patterns & Shortcodes](https://github.com/mattcowan/find-blocks-patterns-and-shortcodes)** — a WordPress admin tool that finds which posts use a block, a pattern, or a shortcode. [WordPress.org](https://wordpress.org/plugins/find-blocks-patterns-shortcodes/)
